# Noia Moon Warm 1.0.0b1 — First Public Beta

Noia Moon Warm is a warm-toned complete theme for **Pale Moon**, based on Noia Moon by Lootyhoof and classic Noia / Noia Warm artwork.

## Added
- A classic cream, gold, amber and dark-red browser appearance, with matching toolbars, menus, tabs and dialogs.
- Updated Add-ons Manager icon and theme preview.

## Changed and fixed
- Restored the classic glossy Noia appearance in a cohesive warm palette.
- Recolored the remaining blue expand/collapse arrows in the Bookmarks Sidebar to warm red-brown.
- Preserved accumulated toolbar, downloads, dialog, and Windows titlebar/maximization improvements.

## Installation
Download **`Noia_Moon_Warm_1.0.0b1.xpi`**, install it in Pale Moon, activate the theme, and restart the browser.

**Noia Moon Warm Options 1.0.0b1 is distributed separately on the forum and is not attached to this GitHub Release.** It may later be listed on the Pale Moon Add-ons site.

Do not enable the original Noia Moon Options together with Noia Moon Warm Options: their global styles and overlay IDs may conflict. Both complete themes can remain installed; enable only the matching Options extension and restart when switching.

## Known limitations
- Most hands-on verification was performed on Pale Moon 35.x. Earlier versions and other platforms have not been comprehensively tested.
- The separate Options extension includes an experimental Black palette; some dialogs may still have contrast issues.
