Noia Warm Moon 2.6.0a1 test build
==================================

This is an experimental Pale Moon complete theme fork prepared from Noia Moon 2.6.0.

Base theme:
- Noia Moon 2.6.0 by Lootyhoof
- Noia Fox by David Vincent
- Noia icon set by Carlitus

Warm icon donor used for this test build:
- Noia Warm icons by Carlitus
- GNOME port by Vyacheslav Dikonov, according to the included ChangeLog from the NoiaWarm archive

Changes in a1:
- New theme id: noia-warm-moon@halvar666
- New internal skin name: noiawarmmoon
- Enabled Noia Moon warm icon option as default
- Rebuilt main browser toolbar sprites from Noia Warm stock icons where possible
- Replaced selected Places, menu, alert/dialog and preference icons with Noia Warm variants
- Added mild warm beige/brown chrome palette overrides

Licensing note:
The uploaded NoiaWarm archive did not include a standalone LICENSE/COPYING file. Treat this as a test build until original license files are attached/verified for public release.

a4 toolbar scale correction:
Large toolbar source icons from Noia-Warm.jar are max 32x32; small source icons are max 24x24.
Noia Moon skeleton expects 64x64 sprite regions for large mode and 48x48 regions for small mode; CSS then displays them at about 32px/24px.
a4 upscales normal toolbar art to 60px within 64px cells and 46px within 48px cells to match Noia Moon visual size.
