# Noia Moon Warm 1.0.0b1 — proposed public beta notes

> **RELEASE CANDIDATE — final licensing and cross-platform installation checks are still pending.**

## Added
- New warm gold Add-ons Manager icon and a theme preview image.

- Warm Noia styling across Pale Moon's browser chrome and major XUL dialogs.
- Remastered toolbar, bookmarks, preferences and Add-ons Manager icons.
- Eight bookmark folder colour sets (with the separate Options extension).
- Optional Bronze, Soft Rose and Sage Green colour palettes.

## Changed
- A cream and gold interface replaces much of the original Noia Moon grey/blue palette.
- Optional green close buttons replace the previous blue variant.
- The Options extension now starts at **Default**, keeping Noia Moon Warm's appearance unchanged unless a new palette is selected.

## Fixed
- Windows 10/11 custom titlebar in the theme, including the maximized window caption buttons and optional Windows titlebar mode (confirmed on the maintainer's Windows setup).
- Dark translucent All Tabs panel replaced by an opaque, readable warm panel.
- Various contrast and alignment issues in downloads, Library, installation dialogs and Preferences.
- Several Black palette text/background contrast issues.

## Compatibility with Noia Moon Options
- Noia Moon and Noia Moon Warm complete themes may be installed together.
- **Do not enable the original Noia Moon Options and Noia Moon Warm Options simultaneously.** Enable only the Options add-on for the active theme and restart Pale Moon after changing it. Neither add-on needs to be uninstalled.

## Known issues
- **Black** in the Options extension is **experimental**: some dialogs may still have contrast inconsistencies.
- Changes to folder colour and most palette settings require restarting Pale Moon.
- Cross-platform appearance has not been comprehensively tested; initial testing focuses on Pale Moon 35.x.
