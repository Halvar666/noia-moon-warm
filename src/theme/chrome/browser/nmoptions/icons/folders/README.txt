Noia Warm Moon folder palettes (test assets)

8 colors x 3 sizes x open/closed. Red is the current theme default; the existing
Places icon locations stay unchanged. Other colors are opt-in via Noia Warm
Moon Options. Only the Bookmarks Sidebar is targeted by Options 2.1.2a1.

Colors: red, yellow, violet, orange, grey, green, cyan, blue.
16 and 32 px: user-supplied ready-size icons for 7 alternate palettes.
48 px: user-supplied masters. Red 32 px is derived from red 48 px;
red 16 px is taken from the theme's existing default icon.
Do not delete or reorganize nmoptions when creating a cleanbuild.
