Noia Moon Warm Options 1.0.0b1 — initial public beta (2026-11-07)

- Independent MPL-2.0 XPCOM startup component, replacing historical Stylish-labelled source.
- Maintainer-approved custom 64×64 Add-ons Manager icon.
- All preferences, XPCOM IDs, browser skin registration, and optional palettes preserved from a9.
- Public display name standardized to Noia Moon Warm Options.
- 13 automated startup mock tests passed, and a9 was reported regression-free in Pale Moon 35.

COMPATIBILITY:
Both complete themes can remain installed, but original Noia Moon Options and
Noia Moon Warm Options must not be enabled together. Enable only the Options
extension matching the active theme and restart after switching.

Note for alpha testers: upgrading from an installed 2.1.2a9 may be treated
as a version downgrade; install 1.0.0b1 manually if Pale Moon does not
offer an automatic update. The add-on ID and preferences are unchanged.
